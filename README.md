# ✨ Prism

Prism - это минималистичный инструмент для распознавания текста в документах. Проект создан с упором на эстетику и удобство: чистый интерфейс, плавные формы и мгновенный результат.

## Возможности

- Распознавание русского и английского текста.
- Загрузка файлов JPG, JPEG, PNG.
- Удобное копирование результата в один клик.
- Автоматическое сохранение в файл.

## Требования

- Python 3.9+
- pip

## Установка

1. Клонирование:

git clone <URL_репозитория>

cd <папка_проекта>

python -m venv .venv .venv\Scripts\activate

pip install -r requirements.txt

streamlit run app.py

Использование:

Загрузка файла:
Нажмите на кнопку "Загрузить файл".
Выберите изображение с текстом.

Распознавание текста:
После загрузки файла, Prism автоматически распознает текст и отображает его на экране.
